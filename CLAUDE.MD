# Vates / Tech-Value Guidelines
- Stack: React 18+, TypeScript, Vite, Tailwind CSS, Supabase.
- Architecture: Feature-Driven modular architecture.
- Security Policy: Strict Zero-Knowledge.
- Cryptography Rule: ALWAYS use native `window.crypto.subtle` (Web Crypto API). NEVER install or import external crypto libraries (no crypto-js, no bcrypt).
- TypeScript: Strict types, no `any`.
